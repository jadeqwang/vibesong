# 一笔一画: Shot Script v1

All times are seconds on the song timeline (`analysis/timing.json`, `analysis/lyrics_timed.json`). The tempo accelerates from 140 to 152 BPM, so **every cut keys to the measured beat grid, never a fixed BPM.** Shouted chants cut on `vocal_accent`, not on the consonant onset.

The world has four looks (see `bible.md`), entered in this order. Each transition is drawn by a stroke or performed by the camera, never a plain crossfade.

```
0      14        34   41            67.8      80.8        94.2      110.4   123.4      136.2              161.7   174.4        187    201.2
|INTRO |VERSE 1  |PRE |CHORUS 1     |BUILD    |DROP 1     |VERSE 2  |RAP    |BRIDGE    |FINAL CHORUS      |BUILD  |DROP 2      |OUTRO |
|title |CARTRIDGE (pixel)           |VOID/EDITOR          |TALOS (plaster world, golden hour)          |PAPER+TALOS  |full color  |EVERYTHING     |PAPER |
         Eraser chases ->             vibe coding          ^THE TURN              ^paint flood ^erased    ^perspective lock ^world = 一笔一画
```

Arc in one sentence: **we start out running from the Eraser (agility), we find the edge of the world and write our own (imagination), and we win by changing where we stand (perspective), not by fighting.**

## ACT III: TALOS: the world was 3D all along (1:20.8 to 2:03.4)

## ACT V: DROP 2: the resolution goes up again (2:54.4 to 3:07)

Where the wave passes, the land resolves into a **photoreal aerial landscape**: terraced fields, rivers and roads still tracing the four characters, in real light. The heroes stay tiny dots on the strokes, so no photoreal faces anywhere.
  - Built as an engine render of the aerial → an image model makes a photoreal version of that exact frame (composition locked) → a video model animates the sweep → the engine's subdivision wave reveals it block by block.
